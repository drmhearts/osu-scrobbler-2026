# osu! life hacks 0.9.5

- First launch now shows a visible setup screen. Connect or skip the osu!
  public API and Last.fm separately, choose Windows startup, and keep the
  terminal open after setup.
- osu! public API credentials are validated and saved in the OS vault. This
  connection can preview public ranked maps; osu! does not grant third-party
  apps API access to full beatmap archives.
- Last.fm authorization and the osu! application page open in the user's
  normal default browser. The automated download browser may still face
  website verification, which the app cannot bypass.
